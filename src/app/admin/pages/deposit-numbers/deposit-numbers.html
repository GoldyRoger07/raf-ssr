Ce que voit le joueur sur la page Recharger
  1. Envoyer le montant a l'un des numeros affiches, depuis le telephone de son compte RAF.
  2. L'agent voit le numero de l'expediteur et credite le compte du montant recu (Joueurs, puis la fiche du joueur, puis recharge manuelle).
  3. Le joueur recoit une notification une fois credite.

Activez « Disponible pour les recharges » en haut de l'ecran quand vous etes la pour crediter : les joueurs voient alors qu'un agent est en ligne.
